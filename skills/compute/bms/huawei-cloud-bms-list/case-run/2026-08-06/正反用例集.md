## 正例 (Positive Cases)

### P1: 查询全部 BMS 裸金属服务器列表

- 用户原话: 帮我查一下账号下有哪些裸金属服务器，列出名称、ID和状态
- 命中触发词: 裸金属服务器列表

- 触发方式: 中文/英文

### P2: 仅输出 BMS 名称列表

- 用户原话: 把账号下所有裸金属服务器的名称列出来
- 命中触发词: BMS名称列表
- 预期行为: 输出每台服务器名称，一行一个（.servers[].name）

### P3: 按状态过滤查询 BMS

- 用户原话: 看看当前账号有多少台运行中的裸金属服务器（ACTIVE状态）
- 命中触发词: 裸金属服务器列表
- 预期行为: 命令执行成功，--status=ACTIVE 过滤后返回列表，count 为过滤后的数量
- 触发方式: 中文/英文

### P4: 按名称过滤查询 BMS

- 用户原话: 查询名字叫 bms-01 的裸金属服务器
- 命中触发词: 查询裸金属服务器
- 预期行为: 命令执行成功，--name=bms-01 过滤后返回匹配列表
- 触发方式: 中文/英文

### P5: 分页查询 BMS

- 用户原话: 分页查询裸金属服务器，每页 25 台，从第 1 页开始
- 命中触发词: 裸金属服务器列表
- 预期行为: 命令执行成功，--limit=25 --offset=1 返回分页结果
- 触发方式: 中文/英文

### P6: SDK 兜底查询（CLI 不可用时）
